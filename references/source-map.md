# Source Map

本文件把注册表中的来源标签与可核验的来源元数据分开记录。当前仓库只保存了
“PDF1”“PDF2”及页码标签，没有保存原始 PDF、文件哈希、标题、作者、年份或 URL，
因此不能在此补写未经核验的文献身份。

## PDF1

- 身份：待补充；仓库现有材料仅提供 `PDF1` 页码/章节标签。
- 对应范围：注册表和方法目录中标记为 `PDF1` 的方法，主要覆盖 D00–D08。
- 本仓库使用方式：方法摘要、结构化输入输出、适用条件、限制和 Stata 示例均为本仓库整理；
  不包含原始 PDF 全文。

## 发布前补录要求

若要公开宣称某方法“来自原文”，维护者必须补录完整标题、作者、年份、出版物或来源、
DOI/URL、公开状态、原始文件 SHA-256（如可合法保存）及对应方法范围。补录前应将
注册表中的 `PDF1`/`PDF2` 视为未核验内部标签，而非可独立引用的文献。

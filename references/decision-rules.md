# 决策规则：从“不显著”到规范调整

## 1. 先诊断，不先试模型

按以下顺序工作：

1. 复现并锁定用户的基准结果。
2. 检查数据键、合并关系、单位、缺失值、政策时点、变量公式和面板连续性。
3. 分解显著性变化可能来自：系数变化、标准误变化、样本变化。
4. 根据诊断选择方法，而不是按方法菜单逐个试到显著。
5. 在执行前生成 adjustment plan；执行后把每一次尝试写入日志。
6. 报告全部已批准的设定，包括不显著和方向相反的结果。

## 2. 方法选择优先级

- **A层：数据纠错与基准复现**：重复值、错位、错误合并、变量方向、错误缺失值、错误滞后生成。
- **B层：统计设定修正**：合理聚类、固定效应、变量分布匹配、滞后期、ST处理、综合指标构造。
- **C层：设计扩展与敏感性**：替代代理、样本窗口、异质性、门槛、分位数、不同行业粒度。
- **D层：高风险结果导向操作**：因为p值更小而降低聚类层级、删控制、删年份、改缩尾比例或挑子样本。

## 3. 关键判定

### 聚类
聚类由处理赋值层级和误差相关结构决定。不能按“最保守/最显著”的简单排序选择。

### 控制变量
优先使用处理前混杂变量。政策后变量、中介变量、机械构成变量和高度共线变量需单独标记。

### 固定效应
先写出核心变量的变化层级，再判断固定效应会吸收什么。加入固定效应后，应报告核心变量剩余的组内变异和被删除的singleton。

### 标准化
在样本和线性模型完全相同的情况下，线性标准化通常只改变量纲，不改变t值和p值。显著性变化应追查样本或设定差异。

### 样本窗口与剔除
每个窗口或排除规则必须有制度、数据口径或预先理论依据。滚动窗口必须展示完整路径。

### 滞后
滞后长度来自传导机制。L0、L1、L2都运行时，应全部报告，不能只保留显著期。

### 异质性
优先交互项和正式组间差异检验。一个子样本显著、另一个不显著，不等于两组系数显著不同。

## 4. 显著性改善来源分解

对每次调整计算：

- `coefficient_change_pct = (beta_new - beta_base) / abs(beta_base)`
- `se_change_pct = (se_new - se_base) / se_base`
- `sample_change_pct = (N_new - N_base) / N_base`

并判断主要来源：

- 系数明显增大：可能是测量误差减少、样本构成变化或识别对象改变。
- 标准误明显下降：检查聚类、样本量、残差方差与模型拟合。
- 样本明显变化：不能把结果变化完全归因于模型修正。

## 5. 结论等级

- **A：纠错后恢复显著**——发现明确数据/代码错误，修复后结果稳定。
- **B：模型匹配后显著**——诊断支持更合适的模型或推断设定，结果在合理敏感性下稳定。
- **C：理论扩展后局部显著**——仅在预期滞后、分位或理论群体中出现，明确限定外推。
- **D：对设定高度敏感**——主要依赖特定控制、窗口、聚类或样本。
- **E：规范调整后仍不显著**——现有数据不能精确支持假设；报告置信区间和统计功效。
